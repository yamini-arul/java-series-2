# Java Calculator

A simple command-line calculator built using Java. This application allows users to perform basic arithmetic operations such as addition, subtraction, multiplication, division, and modulus.

## Features

* Addition (`+`)
* Subtraction (`-`)
* Multiplication (`*`)
* Division (`/`)
* Modulus (`%`)
* Division-by-zero handling
* Continuous calculations using a loop
* Exit option using `X` or `x`

## Technologies Used

* Java
* Scanner Class (`java.util.Scanner`)

## How It Works

1. Enter an operator (`+`, `-`, `*`, `/`, `%`).
2. Enter two numbers.
3. The program performs the selected operation.
4. The result is displayed.
5. Enter `X` or `x` to exit the application.
